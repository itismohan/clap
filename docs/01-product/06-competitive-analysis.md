# Competitive analysis

Compare **categories**, not a claim that CLAP clones any named product.

## Category map

| Category | Typical strength | Typical gap vs CLAP thesis |
| --- | --- | --- |
| Marketing cloud / journey (email-centric) | Orchestration, scale, services ecosystem | Weak offer catalog + in-session decisioning |
| Mobile / cross-channel engagement | Push, in-app messages, segmentation | Promo budget, stacking, incrementality |
| On-site personalization | Web experience, A/B | Cross-channel offer system of record |
| CDP | Identity, audiences | Not an offer engine; not sub-100ms decisioning |
| Coupon / loyalty catalogs | Points, gift cards | Not F100 decisioning + campaign intelligence |
| Experimentation-only | Stats rigor | No offer lifecycle or channels |

## Positioning statement

For **CRM and growth teams at large consumer brands**, CLAP is the **offer system of record plus real-time next-best-offer**, integrated with the existing CDP and channels—so promotions attract and convert with governance.

## Competitive plays

**If the client is strong in marketing cloud:** Sell catalog + decisioning API + measurement; export journeys via webhooks or cloud-native connectors later.

**If the client is strong in CDP:** Sell activation: decisioning and offer eligibility using CDP segments as inputs.

**If the client is strong in commerce coupons:** Sell customer-aware eligibility, frequency, personalization, and multi-channel promotion—not another SKU coupon.

## Table stakes to win F100 bake-offs

- SSO (SAML/OIDC), SCIM, audit logs, SOC 2  
- Data processing agreement, residency option  
- Decisioning latency SLO  
- Holdout / experiment  
- Approval workflow for offers and copy  
- OpenAPI + sandbox  

## Differentiation (honest)

| We emphasize | We do not claim |
| --- | --- |
| Offer + decisioning + promo measurement in one bounded product | Replacing the entire marketing cloud in year one |
| Copilot with policy guardrails | Fully autonomous spend without humans |
| Complement CDP | Magical identity resolution without source data |

## Watch list (category vendors)

Marketing clouds, engagement platforms, on-site personalization, retail media offer tools. Refresh this list per RFP; do not lock documentation to a single vendor war-room.
